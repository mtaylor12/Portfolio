Overview

Shot Tracker was built for the parent of a child participating in a clinical trial for a pediatric eye condition. The parent needed a simple, reliable way to log each injection on their phone and share that data with their child's doctor.

Each entry captures the date, dosage amount, injection site, pain level (0–10), whether a reaction occurred, and lidocaine application time. Records can be tapped to edit, and an Email Shots button lets the user send the full log to themselves as a weekly backup — keeping the data safe and ready to share at appointments.

What I Built & Learned

Like my other apps, Shot Tracker uses the browser's localStorage API to store records locally on the device with no backend or account required. Because local storage can be cleared unexpectedly, I added an Email Shots button that formats the full log as plain text and opens the device's mail client — giving the user a simple, reliable way to back up their data weekly and forward it to their doctor.

Building for a real user with a genuine medical need pushed me to think carefully about data safety, clarity of the interface, and edge cases like editing an existing record. It was the most purposeful project I've built — knowing it was actually being used made the details matter more.
