Overview

Heroquest Character Sheet is a native Android app built in Java to manage character data during sessions of the Heroquest board game. Rather than tracking stats on paper that gets lost or damaged mid-game, players can maintain up to six characters at once using a tabbed interface — each tab named after the character and persisted across sessions.

Each character sheet tracks name, species, money, level, attack, defense, body, mind, body points, weapons, items, and spells. A keep-screen-on toggle prevents the phone from sleeping during a game session.

What I Built & Learned

This was my first native Java Android project, a step up from my earlier JavaScript WebView apps. All character data is stored using Android's SharedPreferences API, which serves the same role as localStorage in a web context — persisting data locally on the device without a backend.

The tab system dynamically creates and labels up to six character tabs, with each tab saving its own independent state. The spells section works as a checklist — players type in spell names, and checking a spell strikes it through to mark it as used during a quest. Reset and Delete buttons each trigger confirmation dialogs to prevent accidental data loss, a lesson learned from building real-use apps for actual users.

Building this taught me how Android layouts and Java activity lifecycle work together, how to manage dynamic UI elements programmatically, and how to think about in-session state versus persistent saved state.
